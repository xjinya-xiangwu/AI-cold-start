# 市场规模估算（TAM / SAM / SOM）

## 触发场景

- "这个赛道有多大？"
- "帮我测算一下 XX 市场规模"
- "这个业务的天花板够不够高？"

## 工作流

### 第一步：定义口径（不定义口径的市场规模都是废话）

先和用户对齐三个边界，缺则问：

1. **地域**：中国大陆 / 全球 / 某些城市
2. **客群**：什么行业什么规模的团队（如"50-500 人的电商运营团队"）
3. **计量**：按 GMV、按客单、还是按年度订阅支出

### 第二步：自下而上（主估算法）

```
TAM = 目标客群数量 × 年均可支付上限（含替代方案预算）
SAM = 客群中符合产品形态的部分 × 年客单价
SOM = SAM × 3 年内可触达份额（渠道能力 × 竞争强度约束）
```

每个乘数单独一行列出，标注：**数值 + 来源（公开数据/访谈/行业报告/`[假设]`）+ 敏感度（高/中/低）**。

敏感度 = 该假设变动 ±50% 时结论是否翻转。高敏感假设必须给出验证方法。

### 第三步：自上而下（交叉验证）

用行业报告总盘 × 细分比例链条。与自下而上结果对比：

- 两者差 3 倍以内：正常，取区间并说明差异来源
- 差 3 倍以上：必有口径错位（如把 GMV 当收入、把用户当付费用户），逐项排查后再输出

### 第四步：合理性检验（必做）

回答两个问题：

1. 要达到 SOM，需要多少个客户/多少市占率？这个数字对应的人员规模（销售/CSM）是否现实？
2. 头部竞品的公开收入是否 > 我们估的 SAM？若是，SAM 口径大概率错了。

## 输出规范

- 主体是一张**假设表**（乘数 / 数值 / 来源 / 敏感度），不是一段结论文字
- 结果一律给区间（保守/基准/乐观三档），不给单点
- 结尾附"本估算最脆弱的 3 个假设"及各自的验证动作
- 禁用"市场巨大""前景广阔"类不可验证表述；引用外部数据必须给出处链接或标注 `[待验证]`
