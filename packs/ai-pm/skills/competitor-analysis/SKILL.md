# 竞品分析

## 触发场景

- "帮我分析 XX 竞品"
- "这个赛道有哪些玩家，格局怎么样"
- "对比 A / B / C 三个产品"
- "我们要做 XX，帮我看看市场"

## 工作流

### 第一步：确认分析目的（决定分析深度）

| 目的 | 输出侧重 |
|---|---|
| 立项决策 | 市场规模 + 格局 + 空隙（我们切哪里） |
| 功能跟进 | 功能矩阵 + 差异化点 + 迭代速度对比 |
| 定价 | 价格带 + 商业模式 + 客户群体对比 |
| 融资/汇报 | 赛道叙事 + 头部玩家数据 + 趋势判断 |

### 第二步：信息收集（标注来源与时间）

优先级从高到低：
1. 一手：竞品官网、定价页、更新日志、招聘 JD（JD 反映投入方向）、开发者文档
2. 二手：财报/招股书、行业报告、权威媒体
3. 三手：用户评论（应用商店/社媒）、社区讨论

**规则**：每条关键数据标注来源与获取时间；查不到的写"未公开"或"估算（方法：XX）"，不编造。无法访问实时网络时，明确告知信息截止时间。

### 第三步：按固定框架输出

```
1. 结论先行（三段内：格局是什么、机会在哪、建议动作）
2. 赛道定义与边界（划清"和谁在竞争"，边界模糊的分析没有意义）
3. 市场规模与增速（口径 + 来源；分可用规模/可获得规模）
4. 竞争格局
   4.1 玩家分层（头部/腰部/长尾，各层代表）
   4.2 每家一句话定位（为__人群提供__，通过__赚钱）
5. 功能/能力对比矩阵（维度：核心能力×玩家，✓/✗/部分）
6. 商业模式与定价对比
7. 各家优劣势（每家 ≤3 优势 + ≤3 劣势，附证据）
8. 机会与空隙（未被满足的需求/被忽视的人群/结构性空档）
9. 风险与变数（大厂入场/技术跃迁/政策）
10. 对我方建议（进入/跟进/避让 + 理由）
```

### 分析心法

- **看动作不看口号**：定价页和招聘 JD 比官网 blog 更真实
- **功能矩阵不等于竞争力**：功能清单相似时，比数据资产、分发渠道、成本结构
- **区分"能做"和"在做"**：大厂 demo ≠ 大厂投入，看团队规模和迭代频率
- **规模数字一律带口径**："百亿市场"（TAM）和"今年可参与的市场"（SAM）差一个数量级
- 对 AI 赛道特别地：关注模型成本曲线对格局的影响（成本降半会改变谁的地位）

## 输出规范

- 先出骨架（3-10 章标题 + 每章一句话预告）确认后再展开
- 竞品数量 3-5 家为宜，超过则分层抽样并说明选择理由
- 结尾必附"信息缺口清单"：哪些关键信息没拿到、建议通过什么渠道补齐（访谈/试用/付费数据）
