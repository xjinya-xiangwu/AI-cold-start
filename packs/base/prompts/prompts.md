# 基础包通用 Prompt 库（11 条）

> 用法：`< >` 内替换成你的实际内容。与基础包 19 个 skills 配合使用。

## 决策与评审（4 条）

1. 这两个方案 A/B：<简述>。从效果上限、落地速度、成本、风险、匹配度五维对比，先分级可逆性，再给推荐。
2. 帮我预演向上汇报：<事项描述>。列出上级最可能问的 8 个问题及数据支撑建议。
3. 项目要延期了：<现状>。帮我写延期汇报：事实、原因、影响、新计划、需要的支持——不甩锅不隐瞒。
4. 从这份复盘材料提炼 3 条可复用经验：<粘贴>。每条格式：现象→根因→下次怎么做（可执行动作）。

## 数据与实验（7 条）

5. 上线/执行一周数据：<粘贴数据>。分析：哪些符合预期、哪些异常、异常可能原因（按概率排序）、下一步动作。
6. 用 metric-design 为"<目标>"设计指标口径卡：每个指标带定义/周期/分母/来源。
7. 这个指标涨了但我说不清是不是好事：<指标+背景>。列 5 种可能解释和各自的验证方法。
8. 帮我设计 A/B 实验：<改动+指标>。包括：可证伪假设、样本量预判思路、分流方式、观察周期、止损线、提前停止条件。
9. 老板/客户要一份周报：<原始数据+本周动作>。按"结论先行"写：本周结论 3 条、数据、下周计划、风险。
10. 对比新旧版本效果：<两组数据>。指出差异是否显著、哪些维度变了、建议放量还是回滚。
11. 把今天的会议记录整理成三张表：<粘贴>。决议（含被否方案和理由）/ 行动项（谁、何时、怎么算做完）/ 未决问题（谁拍板）。
