# A/B 实验设计与解读

## 触发场景

- "想 A/B 测一下新定价页"
- "这个改版上线后数据涨了，能说明有效吗？"
- "帮我设计一个实验验证 XX"

## 工作流

### 第一步：假设先行（不可证伪的假设不开实验）

必须写成：

```
如果我们做 [改动 X]，
那么 [指标 Y] 会 [方向+幅度]，
因为 [用户行为机制]。
```

- Y 必须是单一主指标（同时看多个指标挑涨的 = 必然"显著"，属于作弊）
- 附带护栏指标：不允许恶化的指标（如收入实验的留存、延迟）

### 第二步：最小可检测效应（MDE）与样本量（开实验前算，不是看完了补）

- 先问业务方："多小的差异你才会觉得不值得做？"——这个数就是 MDE
- 样本量经验参照（95% 置信、80% 功效、双尾）：

| 基线转化率 | 检测相对 +10% | 检测相对 +20% |
|---|---|---|
| 5% | 每组约 5 万+ | 每组约 1.3 万+ |
| 20% | 每组约 1.2 万+ | 每组约 3 千+ |

- 流量不够时的出路：加大 MDE（接受只能测出大效果）/ 延长周期 / 改用-switchback 等设计。**禁止**"先跑了再看显著性"
- 标注 `[需计算器复核]`：正式立项前用样本量计算器或统计同学复核上表

### 第三步：分流与周期设计

- 分流单元与实验单元一致（按用户分流的不能按会话算样本）
- 周期 ≥1 个完整周（覆盖周内节律），避开大促/改版/公关事件窗口
- 新功能防新颖效应：观察期数据分第 1 周 vs 之后分别看

### 第四步：预设止损与判定规则（写进实验文档，跑完不许改）

- 止损线：主指标相对跌幅 >X% 且持续 N 天 → 提前终止
- 判定：预设显著水平（默认 α=0.05），主指标置信区间不跨 0 才算显著

### 第五步：结果解读三问

1. **统计显著吗？** 置信区间跨 0 → 未证实，写"未检测到差异"而非"无差异"
2. **业务显著吗？** +0.01% 的显著提升可能不值得维护成本——对照第二步的 MDE 判断
3. **机制对吗？** 指标动了，但方向或分层数据与假设机制矛盾 → 怀疑混杂因素（季节、新奇、分流污染），不得直接采用

## 输出规范

- 实验文档固定结构：假设（含机制）/ 主指标+护栏 / MDE 与样本量 / 分流与周期 / 止损与判定规则 / 结果与三问结论 / 决策建议
- 结果只报：效应量 + 置信区间 + p 值三层，缺一不可
- 单组前后对比（无对照组）必须显式标注"非因果结论，仅关联观察"
