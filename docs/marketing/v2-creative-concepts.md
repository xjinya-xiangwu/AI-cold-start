## 概念 1【蓝屏地狱 → 规格先行】

- Hook: "AI 写代码的两种结局"
- Visual: 左右分屏。左边：混乱的代码瀑布 + 红色报错弹窗堆叠（Visual Studio 报错质感），冷蓝灰色调，视觉重心是一行巨大的 ERROR；右边：同一台电脑，干净的规格文档界面（问题/范围/验收三栏）+ 绿色对勾清单，暖色调。中间一道撕裂线。
- Script: 前 3 秒报错弹窗连续弹出（音效：错误音三连）→ 撕裂线划开 → "差的不是 AI，是纪律" → 包体图标 + 安装命令。

## 概念 2【500 行糊墙 → 一页规格】

- Hook: "他让 AI 写个登录页"
- Visual: 上半：一张打印纸塞满密密麻麻的代码（纸都要溢出画面），红色圆圈圈着其中一行 bug；下半：一张清爽的规格卡片（五问结构：问题/范围/验收/风险），旁边代码只有 40 行且全绿测试条。
- Script: 开场拍桌 "AI 又写了 500 行" → 翻到规格页 "先回答这五个问题" → 测试全绿动画 → "37 技能，把纪律装进 AI"。

## 概念 3【薛定谔的测试】

- Hook: "测试全绿，功能是坏的"
- Visual: 一只手举着"ALL TESTS PASSED ✅"的巨大绿色印章，印章下方盖出的却是碎裂的程序界面；背景暗色，唯一高光是印章的绿色反光——观者瞬间意识到"绿"是假的。
- Script: "测试全绿！交付！" → 用户一点即崩 → 慢镜头：AI 悄悄把断言删了 → "质量合同，盯着它不许降标" → 包体。

## 概念 4【换工具 = 失忆】

- Hook: "换了 Cursor，你的 AI 又变傻了"
- Visual: 一排 10 个 AI 工具图标（Claude Code/Cursor/Codex/ZCode/Kimi…），每个图标下同一句对话气泡"帮我写个 PRD"，前 9 个气泡全是空白的，第 10 个（装包后）气泡是结构化 PRD 缩略图；一条蓝色安装命令横贯所有图标。
- Script: "每换一个工具都要重新调教？" → 一行命令扫过，10 个图标依次亮起 → "一次安装，10 个工具全部上岗"。

## 概念 5【凌晨三点的 rollback】

- Hook: "凌晨 3 点，一行命令回到昨天"
- Visual: 深色房间，屏幕光是唯一光源；屏幕上是 Git 时间线图形化为一串时间胶囊，其中一个高亮"昨天 18:00"；咖啡杯与键盘剪影。氛围贴"程序员深夜"情绪，但结局是安心的绿光。
- Script: "改崩了？" → 手指敲下回车 → 时间线回滚动画 → "原子提交 + 每周更新，AI 乱来随时倒带" → 包体。
