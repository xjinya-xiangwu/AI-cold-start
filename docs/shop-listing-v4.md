### 详情页正文

**你也在经历这些吗？**

- 让 AI 写个功能，它一次糊 500 行——跑不起来，还没法review
- 说好的改个 bug，改完另一个功能悄悄坏了
- 每次换一个新的 AI 工具，之前的"调教"全部作废
- 代码越堆越多，没人（包括你自己）知道哪些能删

**问题不在 AI 不够聪明，在于它没有一套编码纪律。vibe coding 方向把这套纪律装进你的 AI。**

**12 个防翻车技能，覆盖"想法→上线"全程**

| 阶段 | 你对 AI 说 | 装包后 |
|---|---|---|
| 开工前 | "我想做个××" | 先出结构化规格：问题/范围（含不做清单）/验收标准，不确认不动手 |
| 写功能 | "帮我实现××" | 先写失败测试再实现（TDD 红绿循环），薄切片交付每步可验证 |
| 用框架 | "接一下这个 API" | 行为对齐官方文档并留出处，不用过时模式瞎猜 |
| 交付前 | "检查一下代码" | 五轴评审（正确/可读/架构/安全/性能）+ 安全加固清单 + 简化重构 |
| 天天改 | "改个配置" | Git 原子提交纪律，回滚粒度细到单点 |

**10 条即用指令**：出规格 / 拆切片 / TDD 实现 / 五轴自查 / 安全审计 / 原子提交序列……直接粘贴就能用。

**零 API key**。**只新增不覆盖**（自动备份可回滚）。**每周更新**，购买含 3 个月。
