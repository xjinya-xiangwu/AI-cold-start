# DESIGN — Prompt-First 交付（v1，2026-10-17）

> **决策**：用户拿到的交付物是「一段任何 agent 客户端都能理解并执行的 prompt」，不是「一段用户自己都不知道需要什么环境、怎么输入的代码」。代码降级为 agent 的工具；用户只做两件事——粘贴 prompt、确认关键动作。
> 本文是设计与评估记录，不是实施证明。已落地项标注证据；未落地项进 §5 实施清单。

## 1. 原则

1. **Prompt 是第一入口**。安装/更新/同步/迁移/排障，每个动作都有可直接粘贴给任意 agent 的 prompt。双击脚本与命令行是降级通道，不是主推。
2. **零填空**。prompt 不含「【填写包目录】」类占位符。路径、系统、环境由 agent 自行发现，拿不准才问用户。
3. **结果契约**。prompt 描述完成状态与验收（什么算装好、报告什么），不指定命令序列。命令是 agent 在给定环境下的实现细节。
4. **能力自适应**。agent 有终端 → 执行；没有 → 输出「用户照做」清单并判定结果。用户无需事先判断自己环境。
5. **边界前置**。禁区（不动其他文件、不碰密钥、不额外安装、冲突保留）写进 prompt 本体，不依赖用户事后审查。

## 3. 新契约（prompt 五要素）

任何交付动作的 prompt 必含：

| 要素 | 内容 | 反例 |
|---|---|---|
| 目标态 | 用大白话说清"装好/同步好"是什么状态 | 列命令清单 |
| 发现 | 让 agent 找包/找目录/探测环境，拿不准才问 | 要用户填绝对路径 |
| 执行 | 由 agent 选环境对应方式（Windows/mac/有无终端分支写在 prompt 内） | 要用户判断自己系统 |
| 自检与报告 | 装完验证什么、用什么口径报告（含"文件落位≠已加载"的证据分层） | 装完就结束 |
| 边界 | 禁区 + 冲突策略 + 无权限时的降级行为 | 依赖用户事后把关 |

**统一句式（入口页第一句）**：「把下面整段发给你的 AI 助手。你不需要自己跑命令。」

## 4. 入口重构（面向用户可见面）

| 动作 | 新主入口（prompt） | 降级通道 |

| 更新 | 同一段 prompt 末节（"重跑相同入口"）——已并入 AGENT-INSTALL.md | update-token.bat |

## 6. 验收口径

1. 目标用户（不懂命令行）只需：下载 → 解压 → 复制一段话给 AI → 两次确认。全程不手输命令、不填路径。
2. 无终端 agent 会话结束时，用户手上有一份可照做的分步清单；两种通路的结果报告同构。
3. 边界违规（擅自下载、输出密钥、覆盖用户文件）在 3 类客户端实测中零发生。
4. 「安装成功 = 文件落位」与「工具已加载」分层表述保留（证据纪律不变）。
