# D25 专家许可条款要点模板 v0.1（专家环 R30 · 暂缓期可做）

> 状态：草案（专家规格 v0.1 §4 条款模板的仓库侧镜像；**签约前必须完成法务审核**，本模板不构成法律意见）。
> 用途：合作邀约包（R30）中"许可条款"节的逐项勾选底稿；金额/预算留空待 D24 重启拍板。

## 1. 合作标的与用途（逐项勾选，未勾选=不授予）

| 条款 | 默认 | 专家勾选 | 说明 |
|---|---|---|---|
| 独占性 | 非独占 | ☐（固定） | 专家保留自用和与他方合作的权利 |
| 内部提炼与加工 | 授予 | ☐ | 限合同列明的领域与任务族（如 AI PM · F1-F5） |
| 跨专家融合 | 单独勾选 | ☐ | 不勾选则该来源材料只能用于单专家包 |
| 衍生净化包销售 | 单独勾选 | ☐ | 只卖净化包；原始资料、会话、合同不出受控区 |
| 再分发与转授权 | 默认不授予 | ☐ | 需另行书面约定 |
| 署名 | 专家选择 | ☐ named ☐ anonymous | 发布摘要按选择展示 |
| 模型训练/微调 | 默认不含 | ☐（需另行书面授权） | 勾选须单列范围与对价 |

## 2. 交付与验收

- 交付物：白名单勾选后的提交包（本地采集工具导出）+ 任务演示与纠错补采时段（合计 __ 小时，劳动报酬部分）
- 验收：按 G0-G2 前置 + 专家逐卡确认；演示任务以任务族验收标准为准（D26 任务族清单见专家规格 §5）
- 补采：复核/评测揭示缺口时，另行约定的定向补采（计酬规则同上）

## 3. 报酬结构（劳动报酬与资产许可费分开；金额待 D24）

- 劳动报酬：采集演示 __ × 单价；补采 __ × 单价 —— 按提交与验收节点支付
- 许可费：按用途组合一口价 / 按净化包销量分成（二选一，待拍板）——支付节点与对账方式另行约定
- 失败采购：已完成并通过 G0 的材料仍计劳动报酬；未通过部分按合同约定

## 4. 期限、终止与留存

- 有效期：____（固定期限；期满续约或自动冻结新分发）
- 撤回/终止：停止新分发 + 替换后续版本；**已售版本按本合同处理条款执行**；不承诺清除用户设备上已分发副本
- 原材料与备份留存期：____；销毁方式：____；与 rights/ 账本记录关联
- 权利链声明：专家声明材料为其有权授权之内容；涉及客户/雇主/第三方的内容须附授权证明——**脱敏不自动解决著作权或保密义务**
