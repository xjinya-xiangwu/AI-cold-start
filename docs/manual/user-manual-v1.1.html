2. 安装（Windows · 三步）

第 1 步：打开 PowerShell

开始菜单搜「powershell」，点开蓝色图标窗口。

第 2 步：粘贴你的专属安装命令，回车

irm https://asp-registry-xjinya.oss-cn-hangzhou.aliyuncs.com/i/你的token.ps1 | iex

这条命令是你订单的专属凭证（下单时卖家发给你），请保存好；转卖它等于转卖整个订单。以后更新也是这同一条命令。

第 3 步：在选择页勾选并开始安装

命令会弹出本地安装配置页（就在你自己电脑上运行，不经任何服务器）：上面自动列出探测到的 AI 工具（勾你要装的），下面是你购买的内容清单（技能逐项可勾，默认全选），点「开始安装」：

3. 每月内容更新

两种方式任选：

  • 双击 C:\Users\你的用户名\asp-coldstart\update-token.bat（推荐）
  • 或重跑购买时发给你的那条安装命令

▲ 更新运行：重跑同一命令，已装内容增量升级，30 秒完成

想全自动？双击同目录的 enable-weekly-autoupdate.bat 开启每周日 10:00 自动更新（默认关闭；disable-… 随时关）。

▲ doctor 输出：PASS/WARN/FAIL/SKIP 逐条列出（零 MCP 默认配置下全部 SKIP 属正常）

5. 回滚 / 换机 / 卸载

  • 回滚：所有被修改文件的备份在安装目录 _backup/，按报告路径恢复即可
  • 换电脑：新电脑重跑同一条安装命令（token 绑订单不绑机器）
  • 卸载：删除技能目录即可，不影响原工具；需要精确清单就群里找客服

6. 常见问题

Q：要填 API key 吗？
默认功能零 key。可选 MCP 增强的登录都在你的 AI 工具内完成，安装器永不收集任何密钥。

Q：会覆盖我原有配置吗？
不会。只新增，改动前自动备份到 _backup/，重复安装不产生重复内容。

Q：更新要钱吗？
购买含 90 天月度内容更新；之后续更以商品页或客服告知为准。

Q：报错了怎么办？
截图安装报告或报错信息，加微信 xjinya 群里帮看。
