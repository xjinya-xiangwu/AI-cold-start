# 发给你的 AI 助手 —— 复制整段发给任意 AI 即可

我买了一套「智能体冷启动包」技能包，下载链接拿到的压缩包已经在这台电脑上（一般在「下载」文件夹）。请帮我装好。我不需要自己跑命令，你来执行，我来确认。

## 你要做的事

1. **找到包**。解压它（如果还是 .zip）。包目录里应该有 `install.ps1`、`install.sh` 或 `install-windows.bat`。找不到就问我。
2. **先说清楚再动手**。读包里的 `用户手册.html` 和 `delivery-manifest.json`，用大白话告诉我：会往这台机器装什么（多少个技能）、识别到哪些 AI 工具、会改哪些文件。等我说「可以」再继续。
3. **安装**。
   - Windows：运行包里的 `install.ps1`。弹出本地选择页时让我勾选要部署的工具。
   - macOS / Linux：先确认有 python3，再运行包里的 `install.sh`。
4. **装完自检并报告**。确认三件事：技能文件都已落位、每个工具的角色/规则文件内容非空、旧内容有历史备份。然后用大白话告诉我：装好了什么、我该用哪个工具试、怎么试（例如对工具说「用 idea-grilling 拷问我一个想法」）。
5. **提醒我重启 AI 工具**。不重启，新技能不会生效。

## 规矩（不可越过）

- 不开通任何 AI 服务，不额外下载软件，不动我的其他文件，不绕过公司策略。
- 遇到与我已有内容重名：保留我的版本，在报告里列出冲突项。
- 不输出、不记录任何密钥和订单信息。
- **如果你没有本地终端或文件权限**：不要声称已安装。改为给我一份「我照着做」的清单——双击哪个文件、或粘贴哪条命令到哪个终端——我做完把结果贴给你，由你判断下一步。
